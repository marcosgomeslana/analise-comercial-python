# Análise Comercial com Python

## Descrição

Projeto desenvolvido em Python para análise de dados comerciais a partir de arquivos CSV de vendas.

O objetivo é consolidar os dados e gerar indicadores de desempenho que auxiliem na tomada de decisão.

## Funcionalidades

- Leitura automática de arquivos CSV de vendas;
- Consolidação dos dados em uma única tabela;
- Identificação do produto mais vendido;
- Cálculo do faturamento por produto;
- Identificação do produto com maior faturamento;
- Cálculo do faturamento total da loja.

## Tecnologias Utilizadas

- Python
- Pandas
- Google Colab

## Estrutura dos Dados

Os arquivos de vendas contêm informações como:

- SKU
- Produto
- Quantidade Vendida
- Cliente
- Data da Venda
- Loja
- Preço Unitário

## Principais Métricas Analisadas

### Produto mais vendido

Ranking dos produtos com base na quantidade vendida.

### Produto com maior faturamento

Ranking dos produtos considerando o valor total arrecadado.

### Faturamento da Loja

Cálculo do faturamento total gerado pelas vendas registradas.
